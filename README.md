# Nexa — Tech Learning Platform Landing Page 🚀

A modern, responsive landing page for **Nexa**, a fictional technology learning platform designed to help college students learn in-demand skills, build real-world projects, and prepare for their careers.

## 🌐 Live Demo

**Coming soon**

## 📌 About the Project

Nexa is designed as a modern SaaS-style landing page with a clean interface, responsive layout, and clear call-to-action sections.

The project was created to practice and demonstrate fundamental **HTML5 and CSS3** skills while building a realistic portfolio project.

## ✨ Features

* Responsive navigation bar
* Hero section with call-to-action buttons
* Feature cards
* "How It Works" section
* Statistics section
* Student testimonials
* Final call-to-action section
* Responsive footer
* Mobile-friendly design
* CSS hover effects
* Responsive layouts using Flexbox and CSS Grid

## 🛠️ Technologies Used

* **HTML5** — Page structure and semantic markup
* **CSS3** — Styling, layouts, animations, and responsiveness
* **Flexbox** — Flexible layouts
* **CSS Grid** — Structured card and section layouts
* **Media Queries** — Responsive design

No JavaScript or CSS frameworks were used.

## 🎨 Sections

### 1. Navigation

Provides links to the main sections of the website along with a "Get Started" button.

### 2. Hero Section

Introduces Nexa with the main message:

> Build Skills. Build Projects. Build Your Future.

### 3. Features

Highlights the main benefits of the platform:

* Learn Skills
* Build Real Projects
* Track Your Progress
* Prepare for Careers

### 4. How It Works

Explains the learning process in three simple steps:

1. Choose Your Path
2. Learn & Build
3. Launch Your Career

### 5. Statistics

Displays platform statistics such as students, learning paths, projects, and satisfaction.

### 6. Testimonials

Contains fictional student testimonials demonstrating how users could benefit from the platform.

### 7. Call To Action

Encourages visitors to start learning through the "Get Started Free" button.

### 8. Footer

Contains navigation links, resources, company information, and social media placeholders.

## 📱 Responsive Design

The website is designed to work across different screen sizes:

* Desktop
* Laptop
* Tablet
* Mobile

CSS media queries are used to adjust layouts, typography, spacing, and card arrangements for smaller screens.

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/your-username/nexa-landing-page.git
```

2. Open the project folder:

```bash
cd nexa-landing-page
```

3. Open `index.html` in your browser.

Alternatively, use **VS Code Live Server** for easier development.
